# 점지 v0.3

이번 버전은 빠르게 실제 사용해보는 로컬 프로토타입이다.

## 실행
```bash
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속.

## 추가된 것
- 일정 날짜/시간 입력
- 점지 일정 수정/삭제
- 외부 일정과 점지 일정 source 분리
- 오늘 일정 클릭 → 외부/점지에 따라 다른 이동 흐름의 기반
- 일정 변경 후 다시 추천
- 오늘 추천 작업 확정
- 할 일 체크박스 + 0~100% 진행률
- 프로젝트 클릭 → 프로젝트 수정
- 빠른 기록 + 버튼 동작 안정화

외부 캘린더 실제 연동(읽기/쓰기), 모바일 알림/위젯, 서버 동기화는 다음 단계다.
